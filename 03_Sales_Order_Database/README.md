# Sales Order Database – TCL Queries

This project contains TCL (Transaction Control Language) queries performed on a Sales Orders database as part of the Database Systems course.

## Concepts Demonstrated

- START TRANSACTION
- COMMIT
- ROLLBACK
- SAVEPOINT
- ROLLBACK TO SAVEPOINT
- RELEASE SAVEPOINT
- Transaction isolation level
- Transaction-based UPDATE and DELETE operations

## Files

- `tcl_queries.sql` – All 10 TCL queries from the assessment, formatted and commented.

## Dataset

Sales Order Dataset – Kaggle

The SQL is based on the work submitted in the Database Systems Assessment 5 lab.
