# Blood Donation Camp Database

A relational database project developed as part of the Database Systems course.
The database models a blood donation camp involving donors, events, staff, and donations.

## SQL Work Included

- Database and table creation
- Primary and foreign keys
- Constraints
- `ALTER TABLE` operations
- Column modification and renaming
- Index creation
- Data insertion
- `SELECT` queries
- `JOIN` queries
- Filtering and limiting results
- `UPDATE` operations

## Files

- `01_database_setup_and_ddl.sql` — Database creation, table creation, constraints, and DDL operations
- `02_insert_queries.sql` — Data insertion queries
- `03_assignment_queries.sql` — Assignment-based SQL queries
