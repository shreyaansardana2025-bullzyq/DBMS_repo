# Superstore Sales – Arithmetic Operators

Database Systems coursework using the Superstore Sales dataset.

## Topics Demonstrated
- Arithmetic operators: `+`, `-`, `*`, `/`, `%`
- Aggregate functions
- `GROUP BY`
- Window functions with `PARTITION BY`
- Date arithmetic using `DATEDIFF()`
- Calculated fields and business-style analysis

## Source
Superstore Sales Dataset (Kaggle), as used in Assessment 5.

- `arithmetic_operator_queries.sql` – Queries 1–19 from the assessment
