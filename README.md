# Database Systems - Queries

This repository contains my Database Systems coursework and practical SQL work completed as part of the BACSE202 Database Systems course.

## Project Description

### 01. Blood Donation Camp Database
- Database and table creation
- DDL and constraints
- INSERT queries
- Regular and assignment queries
- ER modelling and normalization included in `05_Database_Design`

### 02. Netflix Movies and TV Shows Database
- Database setup and basic SQL queries
- DDL and DML
- DCL and user/privilege management
- 32 queries from the lab assessment

### 03. Sales Order Database
- TCL queries
- Transactions
- COMMIT and ROLLBACK
- SAVEPOINT and ROLLBACK TO SAVEPOINT
- Transaction isolation level

### 04. Superstore Sales
- Arithmetic operator queries
- Aggregate functions
- GROUP BY
- Window functions
- Date arithmetic

### 05. Database Design
Supplementary database-design work:
- ER Diagram
- Normalization: UNF, 1NF, 2NF and 3NF
- BCNF/4NF analysis example
