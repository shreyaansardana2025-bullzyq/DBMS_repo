# Database Design

This section contains supplementary database-design work related to the Blood Donation Camp project and a separate BCNF analysis example.

## Contents

- `ER_Diagram/` – Blood Donation Camp ER diagram and revised ER model documentation.
- `Normalization/` – Normalization work covering UNF, 1NF, 2NF and 3NF.
- `BCNF/` – A worked BCNF/4NF analysis using a Student–Course–Hobby relation.

The design material is included as supporting work; the main focus of this repository is the SQL query work in the other project folders.
